# KG-Compiler — 知识编译器

## 描述

将任意调查素材（对话记录、文章、转录文本等）编译为**人类可读的结构化知识文章**。与 KG-Ingest（机器可查询的知识图谱）互补。

### 与 KG-Ingest 的区别

| 维度 | KG-Compiler | KG-Ingest |
|------|------------|-----------|
| 输出对象 | 人类阅读 | 机器查询 |
| 输出格式 | Markdown 文章、深度解读、教科书 | JSON 命题、Q&A 对、知识单元 |
| 组织方式 | 章节、段落、叙事流 | 原子命题、因果链、标签索引 |
| 典型场景 | "把这篇访谈写成深度文章" | "把这篇访谈存入知识图谱" |

## 使用场景

- 将 AI 对话记录转化为深度解读文章或教科书式汇编
- 将口播/语音转录文本编译为可阅读的知识文章
- 将多篇调研材料聚合为章节化知识体系
- 需要无损保留原始信息但重新组织结构的场景

## 7 步匹配选择架构

```
1. 输入识别 → 判定素材类型和内容特征
2. 内容类型匹配 → 匹配到对应的内容类型
3. 知识单元提取 → 提取关键概念、论证、案例
4. 内容结构选择 → 选择合适的文章结构
5. 输出格式与技法选择 → 匹配输出格式
6. 写作执行 → 生成文章
7. 质量自检 → 检查完整性、准确性、可读性
```

## 9 种输出格式

| 类型 | 格式 | 用途 |
|------|------|------|
| 深度解读 | 论证文章 | 存档 |
| 教科书式汇编 | 章节化知识体系 | 存档 |
| 公众号 | 短段落 + 观点鲜明 | 分发 |
| 商务科普 | 案例 + 数据 + 结论 | 分发 |
| 技术文档 | 结构化 + 代码示例 | 分发 |
| 知乎回答 | 问题导向 + 分点 | 分发 |
| 演讲稿 | 叙事流 + 金句 | 分发 |
| 报告摘要 | 结构化总结 | 分发 |
| 学习笔记 | 要点 + 关联 | 分发 |

## 内容缺口检测

在写作过程中，如果发现素材中缺少某些关键信息，Compiler 会标注内容缺口并提供补充讨论的建议，引导用户补充缺失内容而非强行编造。
